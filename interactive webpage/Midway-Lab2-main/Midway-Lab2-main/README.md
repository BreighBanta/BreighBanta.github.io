Languages used (HTML, CSS, Javascript)

In this lab, we used the base counter structure that we worked on in class, along with some design theories to improve on the webpage. The base design consisted of a background and a container that displayed a number and three different options: increase, decrease, and reset. The webpage allowed the user to inrease or decrease the displayed number from 0, and reset it back to 0. To make the design more accessible to other users, we added a few new features to the program. One of which is the ability to set a goal and see how much progress has been made towards it. To use the feature, enter the desired number in the text box, click the "set Goal" button, and use the add and lower count buttons to achieve the goal.

When planning the new features, we used the principles seen in the diamond method of design and a combination of personal preferences to add new features. First, we talked through a few different design ideas, like a progress bar, a history of numbers, and different color themes. We wanted to see what kinds of different designs we could come up with first. Then we defined what they would look like and how they fit into the rest of the design goal. We then developed the code and tested it. Since Daniel has a little more expereince, he was responsible for programming the Javascript logic and some of the more complex issues that came with the html and css. Meanwhile, Breigh worked on the basic html and css design, and README file. For the new features, we knew that we wanted to make the numbers different colors based on whether they were positive or negative, green for positive and red for negative. Since we have previously worked on a progress bar, we decided on incorporating one somehow. To have a progress bar, we needed to have some sort of goal to work towards, so we decided on adding the goal feature. 

These new features, we thought, would make the webpage easier for the user to look at and use. We amde sure that the container that holds the counter and buttons was highlighted and stood out against the rest of the background, same with the Goal section. By making the number different colors, we wanted to make sure that there was a clear difference in between 0, positive numbers, and negative numbers. The progress bar is also made up of a blue/green gradient, made to stand out against the background and be visible to the user. The progress bar also shows the percentage made towards the goal, also to let the user know more info about there goal number.
