For this project, I used a few different design principles to redesign the Google page we worked on 
in class. One of the first things that I thought about adding was a dark mode for those who prefer 
darker backgrounds. I know that there are a lot of websites that have a feature like this, and it is 
one that I use often. I have also noticed that having a darker background makes it easier to see at 
night, especially on a phone. I assumed that users of the webpage would want to have options when it
came to how they see the page, especially for those who see things differently or just have 
preferences. I also wanted to change the google logo to one that fit the upcoming holidays. 
I know that some people look forward to seeing the different “doodles” that google comes up with to 
celebrate different holidays and seasons. I chose to find one that fit the fall/Halloween theme. 
I also wanted to make some of the buttons and features stand out more and make them more visually 
appealing, to make things easier for the user to see and use.

 

As for the coding process, I had a lot of trouble trying to figure out the javascript side of things.
I was easily able to change the image of the page and created a button and CSS classes for the dark 
mode feature. But when it came to functions, I had to look up what was needed. I got a base idea for
Javascript from an online forum but could not get it to work quite right. I tried to look over 
things on my own, but ultimately used chatgpt to tell me what was going wrong. It pointed out a few
syntax errors and inconsistencies from the multiple changes I tried to make but the dark mode was
still not working. When testing other parts of the page, I noticed that the voiceover feature of 
page was also not working and concluded that I did not link the js file correctly to the 
html file, which seemed to be the issue.
