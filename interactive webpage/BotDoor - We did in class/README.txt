For this redesign, I wanted to make small changes that could make the page easier to look at. I also wanted to make different themes for
different user preferences. I used the same basic principle as the light/dark mode from the previous project to help make an assortment of 
different themes. I wanted to make a theme that didn't use very bright colors, which could be helpful to thoe with eye issues, or those
that just prefer to have duller colors. I also wanted to incorporate colors for the upcoming holidays: halloween and christmas. The theme 
button that I added cycles between these three different modes, as well as the default that we worked on in class. For other aspects of design
I wanted to try to make the webpage easier to look at. I know that the instructions title did not catch my attention at first, so I wanted
to make the lettering bigger and easier to see. I also wanted to make the boxes look nicer, so I used the radius attribute to make the edges
rounder, which I felt fit the cartoon theme of the game. I did have some trouble with the javascript connected to the theme button and had to 
use chatgpt and some other resources to help me figure out what wasn't working and how to fix it.
