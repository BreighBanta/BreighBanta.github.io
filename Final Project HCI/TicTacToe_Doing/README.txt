For this redesign, we were tasked with redesigning a
tic tac toe game. I chose to use different colors, add
a scoreboard, and add some animations.

The game was made using using HTML, CSS, and Javascript.
It follows simple tic tac toe rules.Two players take turms
claiming a box with either an X or and O, until there are 
three X's or O's in a row. There is a scoreboard on either
side of the game board showing how mnay rounds each 
player has won. 

I chose to use some of my favorite colors, purple and grey.
I tried to choose shaded that were easier to see when 
used next to one another. I also tried to make the font
larger and easier to see for everyone. The buttons were
also designed to be easy for everyone to see and read.

To make the boxes stand out, I chose to style the individual
cells. I got some ideas from forums and other websites 
to animate and color the cells when the cursor hovers over 
them.

I also thought that it would be nice to have seperate
scores for each player. For the sake of design, I wanted
them to be displayed on either side of the game board
as it felt more like a competition. This is where I ran
into the most trouble. I got general ideas of a scoreboard
from different forums and online examples, but had
trouble fully understandin the logic and sytax. Here, I
used chatgpt to explain why my code was not working 
correctly and what I needed to do to make the 
scoreboard work correctly.
